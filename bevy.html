Bevy開発を支えるCI/CD・AWS基盤

Rust + Bevyのゲーム開発を題材に、変更を自動検証し、 Windows向けビルド成果物を再現可能な形で管理するための開発基盤を設計・実装しています。

GitHub Repository Pipelineを見る
Why

ゲームそのものだけでなく、ゲームを作る環境を改善する。

開発フロー、テスト、ビルド、成果物管理を整え、 開発者が変更を安全に試しやすい状態をつくることをテーマにしています。

CI/CD Flow

変更から成果物までを一つの流れとして設計する。

Quality & Reproducibility

「動く」だけでなく、変更を安全に検証できる状態をつくる。

Application CI

cargo fmt -- --check、Rust tests、Clippy、--locked付きbuildを変更時に実行します。

Infrastructure test

AWS CDK assertionsとcdk-nagを使い、構成とセキュリティ要件をデプロイ前に検証します。

Artifact metadata

Git SHA、UTC時刻、Rust compiler、Cargo.lock SHA-256、crate名を成果物とともに記録する設計です。

Architecture boundaries

game_runtime → game_logic → game_coreの依存方向を定義し、テストしやすい境界を保ちます。

Verification Status

検証済みと未検証を分けて記録する。

App CIとInfra Testは実行成功を確認しています。一方、現在の検証用AWSアカウント停止中に実行した AWS deployはOIDCによるロール引き受け段階で失敗しており、実環境での正常デプロイ完了は主張していません。
