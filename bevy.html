Bevy開発を支えるCI/CD・AWS基盤

Rust + Bevyのゲーム開発を題材に、変更の自動検証からAWSへのデプロイ、 Windows向けビルド成果物の保管までを一つのCI/CD経路として設計・実装し、実AWS環境でE2E検証しました。

GitHub Repository v1.0.0 Release Pipelineを見る
Why

ゲームそのものだけでなく、ゲームを作る環境を改善する。

開発フロー、テスト、ビルド、成果物管理を整え、 開発者が変更を安全に試し、再現可能な成果物へつなげられる状態をつくることをテーマにしています。 Phase 1では、GitHub ActionsからAWSへのOIDC認証、CDKデプロイ、Windows Release build、S3 Artifact Freezeまでを実環境で確認しました。

CI/CD Flow

Quality & Reproducibility

「動く」だけでなく、変更を安全に検証できる状態をつくる。

Application CI

cargo fmt -- --check、Rust tests、Clippy、--locked付きbuildを変更時に実行します。

Infrastructure test

AWS CDK assertionsとcdk-nagを使い、構成とセキュリティ要件をデプロイ前に検証します。

Artifact metadata

Git SHA、UTC時刻、Rust compiler、Cargo.lock SHA-256、crate名を成果物とともに記録する設計です。

Architecture boundaries

game_runtime → game_logic → game_coreの依存方向を定義し、テストしやすい境界を保ちます。
